08 / Methodology and notes
Raster cells are evaluated using their geographic pixel-centre coordinates. A cell is included when its centre falls inside the selected Census boundary geometry.
Built-up surface is calculated by summing positive GHSL raster values inside the selected AOI. This dashboard assumes the GHSL BUILT-S pixel values represent square metres of built-up surface per cell. Confirm this interpretation against the metadata for the exact GHSL release before using the figures in official reporting.
GHSL epochs 2025 and 2030 should be identified as modelled/projected epochs where applicable, not presented as direct observations.
